# experimental-python-oop-bank-system

An experimental Python CLI application built for practice to demonstrate core Object-Oriented Programming (OOP) concepts, including Inheritance, Encapsulation, and dynamic object management.

## Features
- **User Authentication:** Account creation and login system with duplicate username prevention.
- **Banking Operations:** Deposit and withdrawal transactions with balance validation.
- **Executive Access:** Dedicated verification requiring a 12-number key sequence where the sum of all digits must equal 12 (e.g., entering '1' twelve times).
- **Dynamic Lookups:** Account search implementation using Python generators and iterators.

## OOP Concepts Demonstrated
- **Encapsulation:** Protecting account attributes and restricting direct access.
- **Inheritance:** Class hierarchy where `BankAccount` and `ExecutiveAccount` inherit from the base `Account` class.

## Requirements
- Python 3.x
